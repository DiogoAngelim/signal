# Commitment Fixtures

These fixtures freeze the reusable Risk Divider behaviors after removing finance-specific language:

- normalized weighted allocation
- single target full allocation before caps
- confidence and trust gates
- hard constraint blocking
- global and target caps
- insufficient resources
- missing outcome data fallback
- conflicting soft and cap rules
- extreme variability avoidance
- concentrated opportunity caps
- invalid input normalization

Amounts are expressed in abstract resource units. No fixture assumes stocks, portfolios, brokers, currencies, shares, or asset classes.
