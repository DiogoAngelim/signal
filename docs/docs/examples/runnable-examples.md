# Runnable Examples

Build the example package first:

```bash
pnpm --filter @signal/examples... build
```

Run the smallest Query example:

```bash
pnpm --filter @signal/examples minimal-runtime
```

Run the Query, Mutation, Event example:

```bash
pnpm --filter @signal/examples post-publication
```

Run the HTTP example:

```bash
pnpm --filter @signal/examples http-post-publication
```

The examples live in `packages/examples`.

## What You Learned

The examples are the fastest way to see real Signal behavior without building
an app first.
