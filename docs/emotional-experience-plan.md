# Advanced emotional experience: Signal, Lumina and Symbiosis

Date: 2026-11-17. Scope: Signal decision support, Lumina financial exploration and reusable Symbiosis knowledge. "Links" is interpreted as Lumina from the preceding discussion; no separate Links repository surfaced.

## Outcome and boundaries

Earn relief through clarity, trust through truthful state and meaning through the person's own goals. Do not optimize attachment, time spent, trading activity, guilt, pressure or conversion. Emotional benefit cannot be promised or certified by source code alone. Preserve the approved identity, reversible Practice, no-emoji rule, explicit AI opt-in, provenance and no-trading boundary. This work does not alter native decision gates, risk thresholds, credentials, production schema or brokerage authorization.

## Implementation plan

1. **Shared Signal policy.** Export bounded, pure current-interaction support from `@signal/decision/core`. Recognize explicit EN/PT phrases conservatively, with unknown, quotation, negation, third-person and mixed-cue behavior. Offer Direct, Balanced or Step-by-step preferences, chosen support language and adaptation opt-out. Do not emit a diagnosis, emotional score, persisted profile, execution authority or raw input in the policy result. Stop and correction remain communication boundaries even when adaptation is off.
2. **Real Lumina wiring.** Keep financial phrases, saved-goal copy, false-trade claims and Practice allocation parsing in `signal-framework/adapters/lumina-human-support.ts`, injected with the public generic core API by both consumers. The core has no product interpretation or financial permissions. Evaluate support before horizon, asset or allocation routing. Preserve factual tasks rather than replacing them with reassurance. Only explicit allocation commands may change Practice. Share policy with the server and optional AI instructions; deterministic guidance works without an account/key. Reject known coercion, dependency and false-execution outputs, while documenting that a phrase filter is not a semantic guarantee. Validate preferences, reject undeclared profile fields and check conversation ownership before provider work.
3. **Control and recovery.** Make response controls visible but progressively disclosed; allow immediate correction to Direct mode with adaptation disabled and focus returned to the composer. Keep preferences and derived hints in page memory, reset on New thought/sign-out, and do not write them to analytics or database. Preserve failed drafts without overwriting newer edits. Ignore stale responses after leaving a thought. Distinguish local guided replies from actual saved account messages. Use existing accessible toasts for transient operation feedback; persistent service conditions remain visible.
4. **Meaningful moments.** Acknowledge an actually saved goal or Practice idea without turning saved into achieved, illustrative into owned, or a price move into profit. Returning does not imply background monitoring. No confetti, urgency, streaks, possessive language or forced follow-up. Direct mode bypasses emotional framing. Retain essential risk, source and uncertainty information in every mode. Support-language controls do not claim full application localization.
5. **Symbiosis transfer.** Include ten emotional-experience rules in default agent knowledge and preserve the twelve previous Workbench lessons. Add four separately scoped provisional lessons: support is not authority; preserve concrete tasks; truthful meaningful moments; and evidence instead of affect scores. Export an artifact-bound readiness evaluator that separates technical, browser, human and independent follow-up evidence. Missing, invalid, duplicated, future or mismatched evidence cannot pass.
6. **Verification and human validation.** Test boundaries, arbitrary inputs, no-key/provider failures, owner isolation, correction/opt-out, accidental percentage mutation, actual UI controls, mobile/reduced-motion and persistence disclosure. Run existing repository checks at the final SHA. Prepare a consent-based counterbalanced neutral-versus-supportive study with fictional scenarios. Freeze confirmatory hypotheses, sample-size rationale, thresholds, exclusions and analysis before collecting confirmatory outcomes. Retain adverse reactions and unknowns. Exceptional claims additionally require independent replication and follow-up.

## Self-review and improvements applied

Warm copy is not adaptive behavior: wire real execution paths. Interpretation is uncertain: prefer explicit controls and neutral fallback. Support can become paternalism: preserve task and correction. A model prompt is not enforcement: add deterministic boundaries and limited output checks. Reassurance can conceal risk: keep evidence and downside unchanged. Memory can become surveillance: no inferred emotional persistence. Celebrations can fabricate achievement: name the actual event. Engagement can distort the objective: assess understanding and agency. Automated scores can launder evidence: keep human gates separate. Scope can balloon: preserve existing providers and financial permissions.

## Definition of done and honest release states

Source implementation, exact-head automated checks, hosted acceptance, human acceptance and independently sustained benefit are distinct states. A candidate label is not certification. Existing Meaning/Purpose/Wisdom/domain decision machinery is not replaced or bypassed by this presentation policy. No general emotion-recognition accuracy, calibrated psychological inference, better investment outcome or emotional effect is asserted. English/PT phrase coverage and known-output checks have explicit limitations. No participants, live-model evaluations, production actions or external financial transactions are fabricated.

## Verification integrity and domain separation

Bind each verification stage to the expected commit, Git blob hashes and checked-file snapshots. Keep raw command output alongside the workflow status, and use explicit Bash pipefail when tee captures logs. A green log-capture command is not a passing test. The guard itself tests intentional failures, altered files, missing files and an unexpected commit. Source snapshots are whitelisted; hidden workflow files are included without collecting environment files or secrets.

Preserve the existing core architecture gate rather than excluding support from it. Generic communication support stays in Signal core. Lúmina owns financial phrases, meaningful financial moments and exact illustrative-allocation commands in its product adapter. All prior financial regression cases remain in the product suite; additional generic tests cover trusted, stateless domain patterns and unchanged priority/opt-out behavior.

Goal deadlines are date-only values, not instants. PostgreSQL formats them explicitly as YYYY-MM-DD before driver conversion. HTTP and browser tests must verify the exact date across create, reload and update. Toast assertions target the visible notification region without removing its accessible announcement.

## Human validation protocol

Use fictional finances with informed consent, voluntary participation, skipping and withdrawal. Compare supportive versus Direct presentation using identical facts, controls and task outcomes; counterbalance order and blind assessors where feasible. Include first visit, uncertain factual question, loss/urgency, mistaken inference, opt-out, failed save, saved goal and a return with no verified changes. Include voluntary EN/PT and assistive-technology users without inferring sensitive traits.

Measure comprehension, task success, correction/exit success, perceived agency, unwanted pressure, usefulness, self-reported relief/meaning and adverse reactions. Ask open-ended questions before suggesting emotion labels. Retain missing responses/dropouts. Stop on discomfort, unsafe guidance, inaccessible controls, privacy concerns or misunderstanding of financial execution. Formative pilots discover defects; they do not prove superiority. Confirmatory analysis requires preregistration, power/precision rationale, uncertainty and negative results. Bind reports to exact source/policy, consent process, protocol, anonymized cohort, reviewer and report digest. Independent reviewers must inspect actual artifacts; metadata alone cannot authenticate them.
